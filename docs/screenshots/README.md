## 换图约定

README 用的是单图引用（`<img src="docs/screenshots/01-panel.png" ... />`），换图不影响文字。
想做深色/浅色两套时，按 `01-panel-dark.png` / `01-panel-light.png` 命名，再把 README 里的
`<img>` 换成 `<picture>` + `<source media="(prefers-color-scheme: dark)">` 即可。

## 重新截图

1. 打开 DSH 桌面端 → 左侧「工作台」→ 打开工作台面板；
2. 按上表逐个界面截图，保持窗口宽度 ≥ 1400px（当前截图在 2582px 宽的屏幕上抓取后裁切）；
3. 覆盖本目录同名文件即可，无需改 README。
